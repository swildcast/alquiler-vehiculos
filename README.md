# Plataforma de Alquiler de Vehículos

Proyecto final - Programación para Entornos Web II
Estudiante: Santiago Lince

## Funcionalidades
1. Registro de clientes.
2. Inicio de sesión.
3. Catálogo de vehículos.
4. Filtros por marca, precio, tipo y características.
5. Consulta de disponibilidad.
6. Reserva de vehículos.
7. Cálculo automático del costo del alquiler.
8. Historial de alquileres.
9. Gestión de vehículos por parte del administrador.
10. Panel con estadísticas de alquileres.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- Git/GitHub
